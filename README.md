Entry for the [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) bounty **"Funniest Time Machine Warning Label"**.

`main.py` writes a single original one-line warning label to `$MAKEFUN_OUTPUT_DIR/entry.txt` — a dry safety notice that turns the grandfather paradox into the joke and saves the twist for the last few words:

> WARNING: Killing your own grandfather voids the warranty and may cancel the operator.

Deterministic, no network, no randomness, no external files. The program reads the file back and self-checks that it is exactly one non-blank line of 1–120 characters, exiting non-zero otherwise.
